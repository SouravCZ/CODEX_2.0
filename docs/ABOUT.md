# About This Project

## Project Title
**AI Emotional Drift Journal**

## Overview
AI Emotional Drift Journal is a smart wellness companion designed to help users understand their emotional state over time through a combination of facial emotion recognition, AI journaling, and memory-based behavioral analysis.

The main goal of the project is to detect emotional patterns and possible behavioral deterioration early by analyzing what the user writes, how they look, and how their mood changes across time. Instead of just recording feelings, the app tries to **understand emotional drift** and provide meaningful insights.

This project is built as a hackathon-focused prototype, so the emphasis is on innovation, user experience, and a strong demo rather than full-scale production deployment.

---

## Problem Statement
People often do not notice when their mood, behavior, or emotional state slowly worsens over time. Most journaling apps only store text, and most emotion apps only show a snapshot of the current moment.

This project solves that by combining:
- facial emotion recognition,
- AI-powered journaling,
- memory of past entries,
- and trend-based behavioral analysis.

The system aims to answer questions like:
- Is the user feeling worse compared to previous days?
- Are there repeated negative patterns in their journaling?
- Does the facial expression match the written mood?
- Is the user emotionally stable, improving, or deteriorating?

---

## What the Project Does
This application will allow a user to:

- Record or upload a facial image or short video.
- Write a daily journal entry or mood note.
- Analyze facial emotion from the image.
- Analyze the journal text using AI.
- Store memory of past moods, themes, and emotional trends.
- Compare current emotional state with previous history.
- Predict whether the user is emotionally stable, improving, or deteriorating.
- Display a personalized wellness insight dashboard.
- Suggest simple actions such as rest, breathing, reflection, or self-care.

---

## Core Features

### 1. Facial Emotion Recognition
The app captures a user’s face through webcam or image upload and detects emotional signals such as:
- happy
- sad
- neutral
- angry
- stressed
- tired

This gives the system a visual emotional snapshot of the user.

### 2. AI Journal
The user can write a short journal entry describing their day, thoughts, or feelings.

The AI processes this journal to detect:
- sentiment,
- emotional tone,
- stress indicators,
- recurring concerns,
- positivity or negativity in language.

### 3. Memory-Based Analysis
The project keeps a memory of past entries and emotional patterns.

This memory helps the app understand:
- what the user has been feeling recently,
- whether a certain issue keeps repeating,
- how mood changes over days or weeks,
- what common emotional triggers appear in journal entries.

### 4. Emotional Drift Detection
The system compares current mood with past behavior to identify emotional drift.

It tries to classify the user as:
- stable,
- improving,
- or deteriorating.

This is one of the most important parts of the project because it makes the app feel intelligent rather than just reactive.

### 5. Personalized Insights
The app generates simple, human-friendly insights such as:
- “You’ve had low energy for three days.”
- “Your facial emotion and journal tone both suggest stress.”
- “Your mood has improved since your last check-in.”
- “You may need rest and a short reset today.”

### 6. Dashboard and Visualization
The user can see:
- mood trends,
- emotional history,
- journal summaries,
- drift score,
- and recommended next steps.

This makes the experience easy to understand and visually engaging.

---

## How It Works

### Step 1: User Check-In
The user opens the app and submits:
- a selfie or webcam image,
- and a short journal entry.

### Step 2: Emotion Detection
The facial image is analyzed to detect emotional cues.

### Step 3: Journal Understanding
The text is sent through AI analysis to identify mood, stress, and tone.

### Step 4: Memory Comparison
The system checks the current input against previous entries and emotional history.

### Step 5: Drift Prediction
The AI estimates whether the user’s emotional condition is stable, getting better, or getting worse.

### Step 6: Insight Generation
The app creates a summary and gives a small wellness recommendation.

### Step 7: Dashboard Display
The results are shown in a clean dashboard for the user to review.
